# OnCuidar

Proyecto de título: app móvil de apoyo a cuidadores de niños, niñas y adolescentes con cáncer.

| Carpeta | Contenido |
|---|---|
| [`OnCuidar-App/`](OnCuidar-App) | App Flutter, API REST (Node.js + Express), base PostgreSQL y Docker Compose. Empieza por su `README.md`. |
| [`OnCuidar-Latex/`](OnCuidar-Latex) | Informe de título en LaTeX (`LatexProyecto/`, compilar con `latexmk -pdf main.tex`). |

Esta rama usa un backend propio (sin Firebase). La versión anterior, con Firebase, está en la rama [`release/v1-firebase`](../../tree/release/v1-firebase).
